# Calendar

<Spacer y={0.8} />

Displays a calendar from which users can select a date or range of dates.

<Spacer />

### Default

<Editor
  scope={{ Calendar }}
  code={`() => {
  const [value, setValue] = React.useState(null);
  const now = new Date();
  return <Calendar allowClear value={value} onChange={setValue}
    minValue={new Date(now.getFullYear(), now.getMonth() - 2, now.getDate())}
    maxValue={new Date(now.getFullYear(), now.getMonth() + 2, now.getDate())} />;
}`}
/>

<Spacer y={2} />

### Horizontal Layout

Use `horizontalLayout` to align content horizontally within the calendar popover.

<Editor
  scope={{ Calendar }}
  code={`() => {
  const [value, setValue] = React.useState(null);
  return <Calendar value={value} onChange={setValue} allowClear horizontalLayout showTimeInput={false} popoverAlignment="center" />;
}`}
/>

<Spacer y={2} />

### Sizes

Choose between `medium` (default) and `small` for size.

<Editor
  scope={{ Calendar }}
  code={`() => {
  const [value, setValue] = React.useState(null);
  return <div style={{ display: "flex", flexWrap: "wrap", gap: 24 }}>
    <Calendar size="small" value={value} onChange={setValue} />
    <Calendar size="medium" value={value} onChange={setValue} />
  </div>;
}`}
/>

<Spacer y={2} />

### Presets

Provide common date ranges.

<Editor
  scope={{ Calendar }}
  code={`() => {
  const [value, setValue] = React.useState(null);
  const end = new Date();
  end.setHours(23, 59, 59, 999);
  const presets = Object.fromEntries([3, 7, 14].map(days => {
    const start = new Date();
    start.setDate(start.getDate() - days);
    start.setHours(0, 0, 0, 0);
    return [\`last-\${days}-days\`, { text: \`Last \${days} Days\`, start, end }];
  }));
  const lastMonth = new Date();
  lastMonth.setMonth(lastMonth.getMonth() - 1);
  lastMonth.setHours(0, 0, 0, 0);
  presets["last-month"] = { text: "Last Month", start: lastMonth, end };
  return <Calendar presets={presets} value={value} onChange={setValue} allowClear />;
}`}
/>

### Min and max dates

Set the earliest and latest allowed dates.

<Editor
  scope={{ Calendar }}
  code={`() => {
  const [value, setValue] = React.useState(null);
  const min = new Date(); min.setDate(min.getDate() - 1); min.setHours(5, 0, 0, 0);
  const max = new Date(); max.setDate(max.getDate() + 1);
  return <Calendar value={value} onChange={setValue} minValue={min} maxValue={max} />;
}`}
/>

### Pinned timezone

Use `pinnedTimezone` to fix the timezone and show it as text.

<Editor
  scope={{ Calendar }}
  code={`() => {
  const [value, setValue] = React.useState(null);
  return <Calendar value={value} onChange={setValue} pinnedTimezone="America/Los_Angeles" popoverAlignment="center" />;
}`}
/>
