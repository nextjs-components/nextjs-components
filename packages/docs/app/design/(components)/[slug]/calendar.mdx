# Calendar

<Spacer y={0.8} />

Select a date or date range. Choose two days to commit a range, or type dates and times and select Apply.

Calendar uses the library's shared Tailwind styles and design tokens. Tailwind CSS 4 or later is required. Load `nextjs-components/src/styles/globals.css` and configure the theme provider as shown in the [installation guide](/design/introduction). The package includes compiled utilities; no package source scanning is required.

```tsx
import { Calendar, type DateValue, type RangeValue } from "nextjs-components";

const [value, setValue] = React.useState<RangeValue<DateValue> | null>(null);
<Calendar value={value} onChange={setValue} allowClear />;
```

### Presets

Provide a record of named ranges. The callback also receives the selected preset key.

On small screens, presets open in a drawer with search and a Done button. Select a range to apply it. Done closes the drawer without changing the selection.

<Editor
  scope={{ Calendar }}
  code={`() => {
  const [value, setValue] = React.useState(null);
  const end = new Date();
  end.setHours(23, 59, 59, 999);
  const presets = Object.fromEntries([3, 7, 14].map(days => {
    const start = new Date();
    start.setDate(start.getDate() - days);
    start.setHours(0, 0, 0, 0);
    return [\`last-\${days}-days\`, { text: \`Last \${days} Days\`, start, end }];
  }));
  const lastMonth = new Date();
  lastMonth.setMonth(lastMonth.getMonth() - 1);
  lastMonth.setHours(0, 0, 0, 0);
  presets["last-month"] = { text: "Last Month", start: lastMonth, end };
  return <Calendar presets={presets} value={value} onChange={setValue} allowClear />;
}`}
/>

### API

| Prop                                    | Type                                    | Default / behavior                                 |
| --------------------------------------- | --------------------------------------- | -------------------------------------------------- |
| `value`, `defaultValue`                 | `{ start: Date, end: Date } \| null`    | Controlled or initial range                        |
| `onChange`                              | `(range, presetKey?) => void`           | Receives native `Date` values; `null` when cleared |
| `minValue`, `maxValue`                  | `Date`                                  | Inclusive date and time limits                     |
| `presets`                               | `Record<string, { text, start, end? }>` | Common ranges; omitted end uses today              |
| `presetIndex`                           | `number`                                | Initial preset index                               |
| `size`                                  | `"small" \| "medium"`                   | `"medium"`                                         |
| `compact`, `stacked`, `hideDateButton`  | `boolean`                               | `false`                                            |
| `horizontalLayout`                      | `boolean`                               | `false`; fields beside the month on wide screens   |
| `showTimeInput`                         | `boolean`                               | `true`                                             |
| `pinnedTimezone`                        | IANA timezone string                    | Local timezone, with a UTC switch                  |
| `popoverAlignment`                      | `"start" \| "center" \| "end"`          | `"start"`                                          |
| `selectionMode`                         | `"range" \| "single"`                   | `"range"`                                          |
| `allowClear`, `disabled`                | `boolean`                               | `false`                                            |
| `width`                                 | `number \| string`                      | `250px`; `180px` when compact                      |
| `defaultOpen`, `isOpen`, `onOpenChange` | Open state controls                     | Closed                                             |
| `buttonClassName`, `className`          | `string`                                | Trigger and outer wrapper classes                  |
| `ref`                                   | `Ref<HTMLButtonElement>`                | Date trigger                                       |

`DateRangePicker` is also exported. Existing internationalized date values remain accepted as inputs. New change callbacks return native JavaScript dates.

### Keyboard

Use arrow keys to move by a day or week. Home and End move to month boundaries. Page Up and Page Down change the month; add Shift to change the year. Enter or Space selects the focused day. Escape closes the popover and returns focus to its trigger.

Typed fields accept `Sep 9, 2026`, `2026-09-09`, or `9/9/2026`, with 12-hour or 24-hour times. Invalid dates, times, and ranges show an error and remain open.
