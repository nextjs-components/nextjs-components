### Language switcher

<Editor
  scope={{ CodeBlock }}
  code={`() => {
  const [language, setLanguage] = React.useState("js");
  const code = \`function MyComponent(props) {
  return (
    <div>
      <h1>Hello, {props.name}!</h1>
      <p>This is an example React component.</p>
    </div>
  );
}\`;
  const switcher = {
    value: language,
    onChange: setLanguage,
    options: [
      { label: "JavaScript", value: "js" },
      { label: "TypeScript", value: "ts" },
      { label: "Next.js", value: "next" },
      { label: "JSON", value: "json" },
    ],
  };
  return (
    <CodeBlock
      filename={
        language === "json"
          ? "package.json"
          : "example." + (language === "js" ? "jsx" : "tsx")
      }
      language={
        language === "js" ? "jsx" : language === "json" ? "json" : "tsx"
      }
      switcher={switcher}
    >
      {language === "json"
        ? '{ "name": "example", "private": true }'
        : language === "js"
          ? code
          : code.replace("props)", "props: { name: string })")}
    </CodeBlock>
  );
}`}
/>

### Props

| Prop                    | Type                                       | Default  |
| ----------------------- | ------------------------------------------ | -------- |
| children                | string                                     | Required |
| language                | string                                     | Required |
| filename                | string                                     | None     |
| hideLineNumbers         | boolean                                    | false    |
| highlightedLinesNumbers | number[]                                   | None     |
| addedLinesNumbers       | number[]                                   | None     |
| removedLinesNumbers     | number[]                                   | None     |
| switcher / tabs         | `{ options, value, onChange, ariaLabel? }` | None     |
| textToCopy              | string                                     | children |
| maxHeight               | CSS height                                 | None     |
| headerActions           | ReactNode                                  | None     |
| copyButtonPlacement     | header / overlay                           | header   |
| pure                    | boolean                                    | false    |
| v0                      | ask / build                                | None     |

Line lists use numbers that start at 1. Click a line number to add its link to the URL. Below 600 px, line numbers are hidden. Language selection is controlled by the caller. More than four tabs use a select control. Unknown languages display plain text. `pure` renders only the code surface.
